# Security

If you find a vulnerability in this action or in the API it calls, please write to
admin@rhinotests.com (the contact in https://rhinotests.com/.well-known/security.txt) instead of opening a public issue. Include what you found and how to
reproduce it. We answer within two business days.

If an API token was exposed, revoke it right away in RhinoTests (**CI/CD** page): it
stops working within a minute.
